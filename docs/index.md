# Documentation Index

This directory contains specifications for the Aine Forge Tester application.

## Overview

Aine Forge Tester is a TypeScript/React single-page application designed as a testing ground for agentic coding tools. It demonstrates modern web development practices with React 18, TypeScript, Vite, and automated testing.
